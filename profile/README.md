# FunshiEngine

FunshiEngine es un proyecto de software libre enfocado en el desarrollo de motores gráficos y herramientas relacionadas con gráficos por computadora.
La organización reúne los proyectos, herramientas y recursos relacionados con el desarrollo de FunshiEngine.

## Qué hacemos

FunshiEngine es una organización de desarrollo de herramientas y motores para juegos. Mantenemos un motor escrito en C++17 cuyo núcleo no depende de ninguna API gráfica, junto con una terminal (CLI), un asistente de escritorio y un agente de código que operan sobre él.

## Principios

Las contribuciones son bienvenidas. Antes de realizar cambios importantes, consulta CONTRIBUTING.md y revisa la documentación y arquitectura existente del proyecto.
- **Documentación junto al código** — cada afirmación se comprueba contra el repositorio del que procede.

## Cómo contribuir

1. Elige un repositorio y lee su `README.md` y `AGENTS.md`.
2. Crea una rama desde su rama por defecto (`main` o `develop`).
3. Envía un Pull Request describiendo tu cambio.
