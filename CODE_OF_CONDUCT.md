# Código de Conducta de FunshiEngine

## Nuestro compromiso

El proyecto FunshiEngine busca mantener una comunidad abierta, respetuosa y orientada al desarrollo técnico.

Se espera que todas las personas que participen en el proyecto mantengan un comportamiento respetuoso y constructivo, independientemente de su nivel de experiencia.

## Comportamiento esperado

Los participantes deben:

- Mantener un trato respetuoso y profesional.
- Realizar críticas centradas en el código, las ideas o las decisiones técnicas.
- Aceptar diferentes opiniones y enfoques técnicos.
- Proporcionar comentarios útiles y constructivos.
- Respetar a otros colaboradores y usuarios.
- Contribuir de buena fe al proyecto.

## Comportamiento no aceptable

No se permitirá:

- Acoso o intimidación.
- Ataques personales.
- Amenazas.
- Lenguaje discriminatorio u ofensivo.
- Publicación deliberada de información privada de otras personas.
- Comportamiento destinado a interrumpir deliberadamente el desarrollo del proyecto.
- Cualquier otra conducta que perjudique de forma significativa a la comunidad.

## Aplicación

Los mantenedores pueden tomar las medidas necesarias para mantener un entorno de desarrollo saludable.

Dependiendo de la situación, estas medidas pueden incluir:

- Solicitar modificaciones en una discusión.
- Eliminar comentarios o contenido inapropiado.
- Cerrar issues, discusiones o pull requests.
- Restringir temporalmente la participación.
- Restringir permanentemente la participación en el proyecto.

Las decisiones se tomarán teniendo en cuenta el contexto y la gravedad de cada situación.

## Reportes

Los problemas relacionados con el cumplimiento de este Código de Conducta deben comunicarse de forma privada a los mantenedores mediante los canales de contacto disponibles en la organización.

No se recomienda utilizar issues públicos para denunciar situaciones personales o de acoso.
